# ILILLII local presentation assets

The app now serves its presentation assets locally so the preview does not depend on external font or image requests. No photo is asserted to show an actual Ilillii dish or premises.

## Fonts

- **Manrope**, Google Fonts: variable Latin and Latin-ext subsets, weights 400–800.
- **Noto Sans Ethiopic**, Google Fonts: variable Ethiopic subset, weights 400–700; includes the Ethiopic ranges needed by the Amharic interface.
- Original SIL Open Font License files are retained in `public/fonts/`.
- Font declarations and script ranges live in `src/refinements.css`; the family stack remains in `src/index.css`.
- English interface copy and original provisional Oromo menu names remain visible until approved translations are supplied.
